# Кто из троих?

Статический сайт для игр вроде «Kiss / Marry / Kill»: показывает по три
случайных фото из пачки, без повторов, пока не покажет всех.

## Как добавить фото

1. Положи файлы (jpg/jpeg/png/webp/gif, без пробелов в имени — используй
   `_` или `-`) в папку `photos/` через git push или прямо через
   веб-интерфейс GitHub.
2. После пуша GitHub Action сам пересоберёт `manifest.json`. Руками этот
   файл трогать не нужно — он генерируется автоматически.
3. Имя, которое показывается под фото, берётся из имени файла: `_` и `-`
   становятся пробелами (`Ivan_Petrov.jpg` → «Ivan Petrov»).

## Кто сейчас в колоде

Страница `all.html` (ссылка «Кто в колоде →» на главной) показывает все
фото из `manifest.json` сеткой, с поиском по имени. Битые файлы
подсвечиваются красным.

## Картинки-заглушки

Сейчас в `photos/` лежат 18 сгенерированных мультяшных портретов, чтобы
было на чём проверить игру. Удали их и положи свои фото. Пересоздать
заглушки: `pip install pillow && python3 scripts/generate-placeholders.py`.

## Локальная разработка

```bash
node scripts/build-manifest.js   # пересобрать manifest.json из papки photos/
python3 -m http.server           # открыть http://localhost:8000
node --test                      # прогнать unit-тесты
```

## Как это работает

- `js/deck.js` — тасует пачку и раздаёт тройки без повторов (колода).
- `js/labels.js` — режимы лейблов (пресет / свои / без лейблов) и логика
  прикрепления лейбла к карточке.
- `js/app.js` — связывает всё вместе и рисует интерфейс.
- `scripts/build-manifest.js` — сканирует `photos/` и пишет `manifest.json`.
